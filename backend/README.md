Orch-System backend (demo)

Stack: Node.js, Express, Sequelize, SQLite

Quick start:

1. cd backend
2. npm install
3. npm run dev

Endpoints (examples):
- POST /api/auth/register
- POST /api/auth/login
- GET /api/projects
- POST /api/projects

The DB file is created at backend/database.sqlite (Sequelize sync).
